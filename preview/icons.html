Boss checklist, built from the game's own art

No drawing this time. Every icon is a real hotbar slot cut from the vanilla hotbar sprite with a real vanilla item sprite centred in it. Locked is that same sprite as a flat #555555 silhouette, which is exactly the grey vanilla uses for the empty armour-slot placeholders in your inventory.

The test that matters: does it sit next to the hotbar?

Actual size, real geometry. The hotbar spans ±91 from screen centre, the offhand slot sits just past it, and the boss row occupies ±125 to ±205 - so it cannot touch the hotbar, but it should read as the same furniture. Zoomed 2x underneath each.

Fresh world - all four locked
Mid run - dragon and wither down
Done - all four unlocked

Those use the current pick: Ender Dragon = end_crystal, Wither = nether_star, Warden = echo_shard, Elder Guardian = prismarine_shard. Everything below is the menu - pick per boss, not per set.
